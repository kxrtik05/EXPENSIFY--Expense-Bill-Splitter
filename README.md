## 🌟 Key Features

* **🤖 AI-Powered Receipt Scanning:** Instantly parses printed paper receipts using OpenRouter multimodal vision APIs, automatically extracting merchant names, itemized lines, prices, and tax computations.
* **⚡ Smart Bill Splitting:** Assign specific items to individual friends or split bills evenly with zero manual calculation errors.
* **📴 Offline-First Architecture:** Built with Hive for ultra-fast local storage and instant UI rendering without forced network dependencies.
* **🎨 Minimalist Design:** Clean, modern yellow-themed UI built for speed, clarity, and ease of use.
